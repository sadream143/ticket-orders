# Ticket Orders

Reads order screenshots (offline) and saves the details to Excel.

## Release a new version
1. In `src/app.py` change the number in `APP_VERSION = "1.0.0"`.
2. Upload the changed files to this repository (branch `main`).
3. GitHub builds the installer automatically (Actions tab) and publishes it under Releases.
4. Installed copies show an orange **Update** button.
